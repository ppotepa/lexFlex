# LexFlex Incremental Language Levels

Each level is an executable translation matrix. A case is counted only when
the production CLI parses the source, generates the target through the
interlingua, reparses the target, preserves the assertion/goal kind, and
preserves the canonical semantic hash.

## Iteration Contract

Every next batch follows this order:

1. add production-path cases for one bounded construction family;
2. run the cases and record every source, expected target, actual target,
   semantic hash result and failure layer;
3. fix the owning layer: model, language data, morphology, parser,
   interlingua metadata, generation or CLI;
4. rerun the complete level and regression matrices;
5. publish the level report only when all cases pass.

Reports generated by tests are intentionally stored below `target/`, while
committed markdown reports describe the scope and confirmed totals.
