# lexFlex

A lightweight, resource-efficient **universal meaning representation framework** built on **Interlingua** — a language-neutral semantic core that supports natural languages, formal languages (future), and programming languages (future).

## Architecture

```
Source Language → [Engine: parse] → Interlingua → [Engine: generate] → Target Language
```

- **Interlingua** is the universal protocol — richer than any single language
- **Language engines** are plugins organized in layered abstraction (Layer 0–3)
- **Data-driven** — linguistic knowledge lives in RON data files, not in code
- **Algorithmic morphology** — word forms are generated by rules, not lookup tables
- **Capability-based translation** — validates what target can express before translating

## Stack

- **Language**: Rust
- **Data format**: RON (Rusty Object Notation)
- **MVP languages**: Polish ↔ English
- **Future**: Mathematics, Logic, Python, SQL

## Layered Abstraction

```
Layer 0: IMeaningRepresentation  (universal — all languages)
Layer 1: INaturalLanguage        (PL, EN, DE — morphology, syntax, pragmatics)
Layer 2: IFormalLanguage         (Math, Logic — future)
Layer 3: IProgrammingLanguage    (Python, SQL — future)
```

## MVP Scope (v0.1)

**In scope:**
- Simple sentences: nouns, verbs, adjectives, pronouns
- 7 Polish cases (algorithmic declension)
- Negation, basic questions, coordination
- Temporal reasoning and quantification
- Pronoun resolution within single sentence (basic)
- ~500 concepts per language

**Out of scope (Feature - v0.2+):**
- Conversation/chat/discourse management
- Long-term memory
- Speech act recognition
- Intent extraction
- Response planning
- Multi-sentence coreference resolution
- Complex/subordinate clauses
- Passive voice
- Formal languages (mathematics, logic)
- Programming languages (Python, SQL)
